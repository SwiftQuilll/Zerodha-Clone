# TradeSphere — Stock Trading Platform

TradeSphere is a full-stack stock trading platform inspired by Zerodha. It provides a web interface for exploring market information, managing watchlists, handling orders, and viewing portfolio information.

## Features

- **Portfolio Management:** View and manage portfolio-related information.
- **Watchlists:** Organize stocks for convenient tracking.
- **Order Management:** Interfaces and API endpoints for stock order operations.
- **Market Tracking:** Dashboard views for monitoring market information.
- **REST API:** Backend endpoints built with Node.js and Express.js.
- **Database Integration:** MongoDB with Mongoose schemas for storing application data.
- **Responsive UI:** React-based interface styled with Bootstrap.

## Tech Stack

**Frontend**
- React.js
- JavaScript
- Bootstrap

**Backend**
- Node.js

## Getting Started

### Prerequisites

- Node.js and npm
- MongoDB instance or MongoDB Atlas connection

### Installation

Clone the repository:

```bash
git clone https://github.com/SwiftQuilll/Zerodha-Clone.git
cd Zerodha-Clone
```

Install dependencies in the frontend and backend directories according to the repository structure.

### Configuration

Create the required environment configuration for the backend, including the MongoDB connection URI and any other variables used by the application.

Never commit database credentials, passwords, or API secrets to GitHub.

### Run the Application

Start the backend and frontend using the scripts defined in their respective `package.json` files.

Refer to the source code for the configured ports, routes, and environment variable names.
